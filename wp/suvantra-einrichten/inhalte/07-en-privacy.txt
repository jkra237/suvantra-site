<h2 class="wp-block-heading">In short</h2>
<!-- /wp:heading -->

<h2 class="wp-block-heading">What the program stores on your machine</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Documents, notes, glossaries and settings are kept in your machine’s local storage. On top of that you can write files yourself at any time — as DOCX, EPUB, PDF or as a complete backup. This data leaves your machine only when you pass it on.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>There is no cloud storage, no synchronisation and no access on our side. If you uninstall the program or clear the local storage, the data is gone — so make backups.</p>
<!-- /wp:paragraph -->

<!-- wp:heading -->
<h2 class="wp-block-heading">When the program does reach the network</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Exactly two cases, and both are named here in full:</p>
<!-- /wp:paragraph -->

<!-- wp:html -->
<dl>
  <dt>The German dictionary</dt>
  <dd>
    The dictionaries for English, French, Spanish, Italian, Polish and Portuguese ship
    inside the program. The German one is under a licence that does not permit shipping
    it inside the Store package, so it is fetched once from our web server on the first
    German spell check. In doing so your machine transmits its IP address to the server
    delivering the file, as it does for any web page. No identifier for you or your
    installation is transmitted, and nothing from your document. If you would rather
    avoid the request, pick a different checking language or skip the check.
  </dd>
  <dt>Pictures in pasted content</dt>
  <dd>
    If you paste content from the web that refers to pictures, the program fetches those
    pictures from their source in order to embed them in the document. The request goes
    to the server hosting the picture, not to us. It happens only because you pasted,
    and it carries no credentials.
  </dd>
</dl>
<!-- /wp:html -->

<!-- wp:paragraph -->
<p>Beyond that the program opens no connections. There is no update check, no licence check against a server, no crash reports and no telemetry.</p>
<!-- /wp:paragraph -->

<h2 class="wp-block-heading">The browser version</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>PureQuill Writer can also be used in the browser without installing. That version behaves the same way — the data lives in your browser’s local storage. When the page is requested, the serving host processes technically necessary access data such as IP address, time and the file requested. No cookies are set and no analytics services are embedded.</p>
